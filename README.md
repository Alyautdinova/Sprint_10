# Sprint_10  — UI-тесты для сервиса «Яндекс.Маршруты»

Проект содержит автоматизированные UI-тесты для учебного сервиса [Яндекс.Маршруты](https://qa-routes.education-services.ru/). Тесты написаны на Python с использованием Selenium WebDriver, Pytest и Allure.

## 🛠 Стек технологий

*   **Python 3.x**
*   **Selenium WebDriver** — для взаимодействия с браузером.
*   **Pytest** — фреймворк для написания тестов.
*   **Allure** — для генерации наглядных отчетов.

В рамках проекта протестированы следующие сценарии:

### 1. Подготовка к заказу такси
*   При выборе вида маршрута «Свой» и типа передвижения «Драйв» активна кнопка «Забронировать».
*   При наведении на иконку «i» в правом верхнем углу каждого тарифа отображается всплывающее окно с описанием, которое соответствует ТЗ.

### 2. Заказ тарифа Такси
*   Ввод двух разных предустановленных адресов в поля «Откуда» и «Куда».
*   Выбор вида маршрута «Быстрый» и нажатие кнопки «Вызвать такси».
*   Проверка, что открывается форма заказа со всеми 6 тарифами по ТЗ (один из них активный).
*   Проверка стоимости такси в блоке с подробностями и в основном блоке.
*   Нажатие кнопки «Отмена» — окно закрывается.

### 3. Ожидание и завершение заказа
*   Дождаться окончания таймера поиска машины.
*   Отображается окно совершенного заказа со всеми элементами по ТЗ (заголовок с временем, номер авто, картинка тарифа, блок с информацией о водителе, кнопки «Отменить» и «Детали»).
*   Проверка блока с полями «Телефон», «Способ оплаты», «Комментарий водителю», «Требования к заказу».

## 📊 Генерация Allure-отчета

Для просмотра подробного отчета с шагами и результатами выполните:

```bash
# 1. Запустить тесты с сохранением результатов
pytest --alluredir=target/allure-results --clean-alluredir

# 2. Сгенерировать HTML-отчёт
allure generate target/allure-results -o target/allure-report --clean

# 3. Открыть отчёт локально
allure open target/allure-report
```
